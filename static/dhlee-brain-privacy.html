Privacy Policy

dhlee-brain · last updated 8 September 2026

dhlee-brain is a personal automation agent with exactly one user: its owner, Donghyun Lee. This policy describes how it handles data accessed through Google APIs.

What is accessed

With the owner's explicit consent, dhlee-brain accesses that owner's own Google Sheets, Docs, Slides, Drive files and Calendar events. It accesses no other person's data, because no other person can authorise it.

How it is used

Data is read only to carry out a task the owner has asked for in that moment — for example summarising a spreadsheet or checking a schedule. Content is written back only when the owner instructs it.

Storage and retention

dhlee-brain runs locally on the owner's own computer. It operates no server and no hosted database. OAuth credentials are stored in a permission-restricted file on that computer. Document content is held only for the duration of the task, in local working files the owner can delete at any time.

Sharing

Data obtained from Google APIs is never sold, and is never transferred to any third party, except where the owner directs a specific piece of content to a specific destination as part of a task they requested. There is no analytics, advertising, or profiling of any kind.

dhlee-brain's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

The owner can revoke dhlee-brain's access at any time at myaccount.google.com/permissions. Revoking access immediately ends all API access; local credentials can then be deleted from the machine.
